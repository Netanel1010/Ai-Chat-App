# 🚀 AI Chat App (Full Stack)

אפליקציית צ’אט עם AI שמחברת בין React (פרונט) ל־Node.js (באקנד) + AI שמחזיר תשובות חכמות.

---

## 💡 מה זה עושה?

אתה כותב הודעה →  
השרת שולח ל־AI →  
ה־AI עונה →  
התשובה מופיעה בצ’אט

---

## ⚡ פיצ’רים

- 💬 צ’אט בזמן אמת
- 🧠 AI שעונה על שאלות
- 🔗 חיבור מלא Frontend ↔ Backend
- 🗄️ תמיכה ב־MongoDB (אופציונלי)
- 📦 מבנה נקי ופשוט

---

## 🧱 טכנולוגיות

**Frontend**
- React (Vite)
- JavaScript

**Backend**
- Node.js
- Express

**AI**
- Gemini / OpenAI API

**Database**
- MongoDB (אופציונלי)

## 🚀 איך מריצים

### 1. התקנה

```bash
cd BackEnd
npm install

cd FrontEnd
npm install
```
### 2. הפעלת השרת
``` bash
cd BackEnd
npm run dev
```

### 3. הפעלת האתר
```bash
cd FrontEnd
npm run dev
```
